# 🎧 АУДИОТЕКА PRO — Веб-платформа аудиокниг (audioteka-pro.ru)

Современная высоконагруженная платформа аудиокниг на стеке **Next.js 16 (App Router, Turbopack) + React 19 + Tailwind CSS v4 + SQLite (@libsql/client)**. Каталог аудиокниг, прямой MP3-стриминг без VPN в РФ, фоновый док-плеер с таймером сна и улучшением голоса, сквозной поиск с Debounce, легальный статус информационного посредника (ст. 1253.1 ГК РФ) и готовая интеграция с Яндекс Метрикой.

## 🚀 Настройка DNS для домена audioteka-pro.ru

В панели управления вашего регистратора доменов (Reg.ru, Beget, TimeWeb, Ru-Center, 2domains и др.) откройте раздел **«Управление DNS-зоной»** и добавьте/измените две записи:

| Тип записи | Поддомен (Имя) | Значение (Target / Данные) | Примечание |
|---|---|---|---|
| **A** | `@` (или пусто) | `76.76.21.21` | Основной IP серверов Vercel Anycast |
| **CNAME** | `www` | `cname.vercel-dns.com.` | Алиас для www.audioteka-pro.ru |

> ⏳ *Обновление DNS-серверов у провайдеров обычно занимает от 15 минут до пары часов.*

## 🌐 Подключение домена в Vercel

1. Зайдите в проект на **[vercel.com](https://vercel.com)** ➔ вкладка **Settings** ➔ раздел **Domains**.
2. Введите: `audioteka-pro.ru` и нажмите **Add**.
3. Выберите рекомендуемый вариант перенаправления: редирект с `www.audioteka-pro.ru` на `audioteka-pro.ru` (или наоборот).
4. Как только DNS обновятся, статус станет зеленым (**Valid Configuration**), и Vercel автоматически выпишет бесплатный SSL-сертификат HTTPS Let's Encrypt.

## 📊 Яндекс Метрика (№ 113789185): Настроенные события и цели

Счётчик уже встроен в код страницы и автоматически собирает Вебвизор 2.0, клики, скроллинг и переходы между страницами. Дополнительно в проект интегрированы JavaScript-цели:

1. `play_audio` — запуск воспроизведения аудиокниги или главы
2. `search` — поисковый запрос в каталоге
3. `toggle_favorite` — добавление книги в избранное / на полку
4. `sleep_timer` — установка таймера сна (15, 30, 45, 60 мин или до конца главы)
5. `voice_boost` — включение режима «Чёткий голос» (эквалайзер речи)
6. `share_book` — шеринг ссылки с точным таймкодом
7. `add_bookmark` — добавление персональной закладки с заметкой
8. `genre_select` — клик по жанровому фильтру
9. `partner_channel_click` — переход в партнерский канал «Яндекс Продажи»
10. `dmca_claim_submitted` — отправка заявления правообладателя
11. `contact_form_submitted` — отправка сообщения через форму контактов

Чтобы включить конверсии по этим целям в интерфейсе Яндекс Метрики:
1. Зайдите на **[metrika.yandex.ru](https://metrika.yandex.ru)** в счетчик `113789185`.
2. Перейдите в **Настройка ➔ Цели ➔ Добавить цель**.
3. Тип условия: **JavaScript-событие** ➔ введите идентификатор цели (например, `play_audio`).
