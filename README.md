# Аудиотека PRO

Каталог аудиокниг с онлайн-прослушиванием: серверный рендеринг, поиск, фильтры по жанрам, бесконечная прокрутка и плеер.

Работает на легальном контенте: произведения в общественном достоянии, аудиозаписи проекта [LibriVox](https://librivox.org).

**Сайт:** https://audioteka-pro.ru

---

## Что внутри

| Возможности | Реализация |
|---|---|
| Каталог с бесконечной прокруткой | серверный HTML + клиентский островок догрузки |
| Поиск по названию, автору, чтецу | SQLite FTS5, полнотекстовый индекс |
| Фильтры по жанрам, сортировка | состояние в URL, сервер перерисовывает страницу |
| Страница книги: аннотация, оглавление, отзывы | вкладки через `?tab=`, без клиентского состояния |
| Плеер с перемоткой, скоростью, таймером сна | единый `PlayerContext`, продолжает играть при переходах |
| Избранное | Zustand + localStorage |
| Баннер «Книга недели» | ротация по номеру недели, без планировщика |
| Возврат на главную, кнопка «наверх», хлебные крошки | серверные ссылки, минимум JavaScript |

## Стек

- **Next.js 16.4** (App Router, Turbopack), React 19, TypeScript
- **Tailwind CSS 4** — `@tailwindcss/turbopack`, без `postcss.config`
- **SQLite** через `@libsql/client`, полнотекстовый поиск FTS5
- **Zustand** для избранного, **lucide-react** для иконок
- Развёртывание: nginx + pm2 + Let's Encrypt

## Требования

- Node.js 20 или новее
- 1 ГБ свободной памяти (сборка Next.js требовательна)
- База `audiobooks.db` в корне проекта (528 КБ, лежит в репозитории)
